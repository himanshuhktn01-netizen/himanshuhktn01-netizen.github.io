THE MISSION

ENTER THE WORLD OF GOBLIN SLAYER

Goblin Slayer is a 2D action-survival shooter developed using Python and Pygame. The player must defend a village against continuous waves of Goblins and powerful Bosses. Surviving requires managing ammunition, maintaining health, and using available resources wisely.

YOUR OBJECTIVE

Protect the village

Survive all incoming enemy waves and defeat the enemies attacking the village.

  • WIN Complete all enemy waves.
  • LOSE The game ends when the player's health reaches zero.

BUILT FOR SURVIVAL

GAMEPLAY FEATURES

Every wave brings a new challenge. Manage your resources, fight enemies, and defend the village.

ENEMY WAVES

Face different types of enemies, including Goblins and powerful Bosses, as you progress through the game.

COMBAT SYSTEM

Shoot incoming enemies and defend the village using the game's shooting mechanics.

AMMUNITION MANAGEMENT

Keep track of your ammunition and reload when your bullets run out.

HEALTH SYSTEM

Monitor your player's health and avoid enemy attacks. If your health reaches zero, the game ends.

Survive successive enemy waves and work towards completing every wave to win the game.

BUILT WITH PYTHON

TECHNICAL ARCHITECTURE

Explore the core classes that bring Goblin Slayer to life.

Goblin Slayer is developed using Python and Pygame. The project uses an object-oriented structure to organise gameplay logic into five core classes, each responsible for a specific part of the game.

  • PYTHON
  • PYGAME
CORE CLASS

Player

The Player class manages the player's main attributes and actions, including health, ammunition, wallet balance, shooting and reloading.

CORE CLASS

Bullet

The Bullet class handles bullet creation, movement and the behaviour of projectiles fired by the player.

CORE CLASS

Enemy

The Enemy class manages enemy properties and behaviour, including Goblin and Boss types, health, movement and collision detection.

CORE CLASS

WaveManager

The WaveManager class controls enemy spawning, wave data and progression between successive waves.

CORE CLASS

Game

The Game class manages the main game loop, game states, event handling, drawing and overall interaction between the different components.
